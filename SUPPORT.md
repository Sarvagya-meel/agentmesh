# Support

Use GitHub Issues for reproducible bugs, documentation gaps, and scoped feature
requests.

Before opening an issue:

- Check the latest release notes.
- Search existing issues and pull requests.
- Confirm whether the behavior occurs on `main`, `develop`, or a feature branch.

For setup issues, include the operating system, Python version, Docker version,
selected `COMPOSE_PROFILES`, and the exact command that failed.

Security-sensitive reports belong in the private process described in
`SECURITY.md`, not in public issues.
