# Changelog

All notable changes to AgentMesh are documented here.

AgentMesh follows [Semantic Versioning](https://semver.org/) and uses
Conventional Commits to decide release notes and version movement.

## Unreleased

## v0.1.1 - 2026-09-10

### Changed

- Added DCO enforcement and explicit intellectual-property and third-party notices.
- Automated post-release synchronization back into `develop`.

## v0.1.0 - 2026-09-10

### Added

- Repository release, contribution, security, support, and automation standards.
- Protected-branch workflow for `develop`, `release/*`, and `main`.

## v0.0.1 - 2026-08-22

### Added

- Initial public GitHub release for the AgentMesh runtime.
